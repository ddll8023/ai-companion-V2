# AI Companion 项目结构文档

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 后端框架 | FastAPI 0.115+ | 异步 Python Web 框架，提供 REST API 和 SSE 流式对话 |
| ASGI 服务器 | Uvicorn 0.32+ | ASGI 服务器，用于运行 FastAPI 应用 |
| ORM | SQLAlchemy 2.0+ | Python ORM，管理所有数据库表结构和查询 |
| 数据库 | SQLite | 本地 SQLite 数据库（WAL 模式），所有数据存储在单文件中 |
| 数据验证 | Pydantic 2.0+ | 请求/响应数据模型验证和序列化 |
| 配置管理 | Pydantic Settings 2.0+ | 从环境变量和 `.env` 文件读取配置 |
| HTTP 客户端 | httpx 0.27+ | 异步 HTTP 客户端，用于调用 LLM API |
| 前端框架 | Vue 3.5+ | 渐进式前端框架 |
| 路由 | Vue Router 5+ | 前端路由管理（Hash 模式） |
| 状态管理 | Pinia 4+ | Vue 状态管理 Store |
| HTTP 请求 | Axios 1.18+ | 前端 HTTP 客户端 |
| CSS 框架 | Tailwind CSS 4+ | 原子化 CSS 框架 |
| 构建工具 | Vite 8+ | 前端开发服务器和生产构建 |
| 类型检查 | vue-tsc 3+ / TypeScript 7+ | Vue 组件和 TS 类型检查 |
| 图标库 | Font Awesome 6+ | 图标库（SVG Core + Solid 图标） |
| 桌面壳层 | Electron 43+ | 桌面应用壳层，管理窗口生命周期和 Python 进程 |
| 打包发布 | electron-builder 26+ | Electron 应用打包（DMG/NSIS/AppImage） |
| 语言 | Python 3.11+ | 后端运行时 |
| 语言 | TypeScript | 前端和 Electron 主进程均使用 TypeScript |
| 包管理器 | uv | Python 项目管理（`uv.lock`） |
| 包管理器 | npm | 前端和 Electron 的包管理 |
| 检索索引 | FTS5 + 向量嵌入 | 全文搜索（FTS5）和向量语义检索双通道 |
| 嵌入推理 | FastEmbed + ONNX Runtime CPU | 本地 CPU 嵌入向量推理，无需 GPU |
| 向量存储 | SQLite BLOB + NumPy | 嵌入向量以 BLOB 存入记忆行，NumPy 余弦相似度检索 |
| 嵌入模型 | BAAI/bge-small-zh-v1.5 | 默认嵌入模型，512 维，中英文语义支持 |

### 依赖配置文件

| 文件 | 说明 |
